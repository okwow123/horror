# 03. PC방 · 새벽 4시

## 메타데이터

- **조합 코드**: `J-D-J-C-B-L4`
- **공포 레벨**: L4 (극한 공포 — 현실 자체가 조작됨, 3층은 존재하지 않음)
- **Setting**: J — 편의점 (단독 공간 프록시로 PC방 사용)
- **Protagonist**: D — 대학생
- **Fear Type**: J — 자신이 자신이 아닌 상황 (본인 ID로 로그인된 빈 좌석)
- **Trigger**: C — 거울 (모니터 = 거울의 메타포)
- **Ending**: B — 열린 결말 (난쟁이 자리에 누군가)

## 장르
모더니즘 호러 / 인터넷 시대 공포 / 메타

## 시간
새벽 4시 12분, 7시간째 자리 차지 중

## 장소
서울 강남 PC방 "스피드 넷", 3층, 뒷자리는 항상 비어 있다

## 주인공
- **이름(랜덤)**: 진혁 / 민재 / 도윤
- **신분**: 고등학생, 17세, 지방에서 올라옴
- **성격**: 롤 4년 차, 밤잠이 짧음, 인스타 좋아함
- **습관**: 30분마다 자리에서 일어나서 돌아다님

## 말투
- "아 ㅅㅂ 미니언 왜 이렇게 많아 ㅋㅋ"
- "ㄹㅇ X발"
- 인터넷 밈, 신조어, 의성어
- "ㅅㅂ", "ㄹㅇ", "ㅇㅈ", "ㅎㅇ", "존나"
- 트위치 클립 톤

## 분위기 키워드
뒷자리, 모니터, 헤드셋, 캡짱, 옆자리, 야식

## 핵심 공포 메커니즘
뒷자리에 항상 누군가 앉아 있다. 안을 들여다보면 비어 있다.
**모니터는 켜져 있고, 본인 ID로 로그인되어 있다.**

## 첫 문장 템플릿
> "아 ㅅㅂ 미니언 존나 쎄다. 잠만 화장실. ... 어? 뒷자리 사람 언제 들어왔지?"

## 회차 구조 (5회차)
1. **뒷자리** — 모니터가 켜진 빈 좌석 발견
2. **로그인** — 본인 ID로 로그인된 PC, 화면은 본인 게임 화면
3. **헤드셋** — 헤드셋에서 들리는 본인 목소리, 30분 전 게임 클립
4. **끄기** — 모니터 끄고 도망, 다음 날 다시 와 보니 3층은 폐쇄
5. **4층** — 사장이 "3층은 없다"는 말, 4층의 빈 좌석, 같은 ID

## 변화 요소 (매번 다르게)
- 뒷자리에 로그인된 게임
- 헤드셋에서 흘러나오는 본인 발언
- 3층 폐쇄 이후 캐릭터가 다시 등장하는 층
- 본인 게임 기록에 존재하지 않는 플레이 기록

## 톤 노트
- "ㅋㅋ"가 회차가 진행될수록 ".."로 바뀜
- 인터넷 용어가 점점 의미 있는 단어로 변주됨 ("미니언", "탱커", "데스")
- 1인칭, 실시간 트위치 클립 톤

## 결말
열린 결말. 본인 게임 클립에 "난쟁이" 자리에 항상 누군가 앉아 있다.
