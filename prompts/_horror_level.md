# Horror Level (공포 강도)

5단계 강도 시스템. `_variables.md`의 Level 변수와 함께 쓰인다.
같은 요소 조합이라도 Level에 따라 **분위기와 결말의 강도**가 달라진다.

---

## Level 1 — 불안

**분위기**: 평범한 일상 속에 "이거 뭐지?" 정도의 사소한 이상만 등장.

**등장하는 요소 예시**:
- 이상한 소리 (계단, 천장, 환풍구)
- 설명되지 않는 물건 (현관에 놓인 안경, 냉장고 안의 음식)
- 반복되는 행동 (본인이 한 기억이 없는 행동)
- 사소한 시간 오류 (시계가 10분 빠르게 감)

**결말**: 이상은 설명되지 않고 일상이 계속된다. "내일도 출근해야지."

**독자 경험**: "이거 무서운 건가?" 정도의 미묘한 불편함.

## Level 2 — 의심

**분위기**: 명확한 이상이 있지만 주인공은 "내 착각이겠지"로 넘긴다.

**등장하는 요소 예시**:
- CCTV와 현실이 다름 (모니터엔 없는데 누군가 봤다고 함)
- 주변 사람이 이상하게 행동함 (동료가 갑자기 말을 안 함)
- 존재하지 않는 사람이 등장함 (이름만 들음, 정체 모름)
- 주인공만 기억하는 사건이 있음 (다른 사람은 모름)

**결말**: 의문점은 남지만 공포는 직접 발생하지 않음.

**독자 경험**: "뭔가 이상한데 진짜 공포는 아직이네." 하는 의심 단계.

## Level 3 — 공포

**분위기**: 이상이 실체화. 주인공도 더 이상 무시 못 함.

**등장하는 요소 예시**:
- 주인공을 누군가 따라옴 (발소리, 시선)
- 죽은 사람과 접촉 (전화, 문자, 물건)
- 공간이 현실과 다르게 변함 (방이 하나 더 생김, 층이 바뀜)
- 주인공만 보는 존재 (거울, CCTV, 사진)

**결말**: 공포의 실체가 한 번 드러나지만, 정체는 완전 설명되지 않음.

**독자 경험**: 소름 돋는 순간이 있고, 끝나고 한동안 생각하게 됨.

## Level 4 — 극한 공포

**분위기**: 현실 자체가 흔들림. 주인공의 정체, 시간, 공간 모두 의심됨.

**등장하는 요소 예시**:
- 주인공의 정체가 흔들림 (죽은 건 나였나, 살아있는 건 누군가)
- 현실 자체가 조작됨 (기록이 바뀜, 다른 사람은 다른 이야기)
- 탈출했다고 생각한 곳이 다시 원점 (루프)
- 본인이 한 일이 본인 기억과 다름
- 다른 캐릭터가 주인공을 모른다고 함

**결말**: 강한 반전. 끝나고 한 번 더 읽게 됨.

**독자 경험**: 끝난 줄 알았는데 무언가 잘못됐다는 느낌. 답답함.

## Level 5 — 여운

**분위기**: 진행 중 강도는 Level 4와 비슷하지만, **마지막 한 문장**에 모든 무게를 싣는다.

**등장하는 요소 예시**:
- 마지막 한 문장으로 의미가 뒤집힘
- 독자가 이야기의 일부가 된 듯한 느낌
- 설명되지 않은 현상을 남김
- "나"가 누군지 모호해짐
- 읽는 동안의 시간과 읽고 난 후의 시간에 결이 생김

**결말**: 한 문장이 모든 걸 바꿈. 끄고 나서 한참 동안 그 문장을 곱씹게 됨.

**독자 경험**: 무서운 장면보다 **여운**이 무섭다. 자기 자신에 대한 공포.

## Level × 분량 가이드

| Level | 권장 분량 | 회차 |
|---|---|---|
| L1 | 1,500~2,000자 | 1편 |
| L2 | 2,000~2,500자 | 1편 |
| L3 | 2,500~3,000자 | 1편 또는 3회차 |
| L4 | 2,500~3,500자 | 5회차 |
| L5 | 1,500~2,500자 (결말에 집중) | 5~7회차 |

## Level 선택 가이드

- **새 시리즈 시작** → L1로 시작해서 L5로 마무리하는 점진적 상승
- **단편 1회성** → L3이 가장 보편적
- **"소름" 위주** → L4 + Ending A (반전)
- **"여운" 위주** → L5 + Ending B (열린 결말) 또는 G (처음 장면 연결)
- **공포 미니멀** → L2 + Ending C (순환)

## 사용 예시

```
"Level 3, Setting B, Protagonist B, Fear C, Trigger B, Ending C"
→ 군부대 + 군인 + 시간 반복 + CCTV + 순환
→ 강도는 중간, 주인공의 보고가 거짓이 되어가는 정체성 혼란

"Level 5, Setting D, Protagonist C, Fear F, Trigger H, Ending B"
→ 지하철 + 택배기사 + 정체불명의 사람 + 문자 + 열린 결말
→ 진행 중 공포보다 마지막 한 문장이 무서운 여운형
```

## LLM 입력 시 주의

Level 숫자만 주면 LLM이 다르게 해석할 수 있으므로 **반드시 키워드도 함께** 준다:

```
Level: L4 — 극한 공포 (주인공의 정체가 흔들림, 현실 자체가 조작됨)
```
