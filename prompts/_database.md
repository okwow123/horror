# Horror Story Generation Database

공포 단편 생성을 위한 **분리된 요소 풀**.
이야기 하나는 각 카테고리에서 1개씩 골라 조합한다. LLM은 이 풀에서 무작위로 뽑거나, 특정 항목을 강제로 지정할 수 있다.

---

## 장소 (Place)

- 폐교
- 오래된 아파트
- 군부대
- 지하철역
- 모텔
- 병원
- 고시원
- 산속 펜션
- 낚시터
- 터널
- 지하주차장
- 무인 편의점
- 오래된 기차역
- 장례식장
- 해안가 마을

## 시간 (Time)

- 새벽 2시
- 새벽 3시 33분
- 비가 심하게 내리는 밤
- 정전 직후
- 마지막 열차가 떠난 직후
- 해가 완전히 진 직후
- 아무도 없는 한밤중

## 주인공 (Protagonist)

- 신입 군인
- 야간 경비원
- 택배기사
- 모텔 직원
- 대학생
- 혼자 사는 직장인
- 경찰관
- 소방관
- 배달기사
- 폐건물 조사원
- 유튜버
- 등산객

## 이상 현상 (Anomaly)

- 존재하지 않는 층의 엘리베이터가 멈춘다.
- 아무도 없는 방에서 전화가 온다.
- CCTV에는 주인공 뒤에 사람이 서 있다.
- 죽은 사람의 전화번호로 문자가 온다.
- 매일 같은 시간에 문을 세 번 두드린다.
- 사진을 찍을 때마다 사람이 하나씩 늘어난다.
- 거울 속의 내가 실제 나보다 늦게 움직인다.
- 녹음 파일에서 미래의 목소리가 들린다.
- 분명 잠근 문이 다시 열려 있다.
- 집 안에 자신이 모르는 물건이 하나씩 생긴다.

## 금기 (Taboo)

- 3층에 올라가지 말 것
- 새벽 3시 이후 문을 열지 말 것
- 이름을 세 번 부르지 말 것
- CCTV를 되돌려 보지 말 것
- 빈 방에서 대답하지 말 것
- 거울을 오래 바라보지 말 것
- 뒤에서 부르는 소리에 대답하지 말 것

## 반전 (Twist)

- 주인공은 이미 죽어 있었다.
- 이야기를 들려주는 사람이 귀신이었다.
- 주인공이 본 사람은 미래의 자신이었다.
- 사건은 과거가 아니라 현재 진행 중이었다.
- 주인공이 탈출했다고 생각한 장소가 사실 같은 장소였다.
- 마지막에 등장한 인물이 처음부터 주인공과 함께 있었다.
- 기록을 남기는 행위 자체가 귀신을 불러오는 의식이었다.

## 결말 (Ending)

- 설명하지 않고 끝낸다.
- 마지막 한 문장으로 모든 상황을 뒤집는다.
- 주인공의 생존 여부를 확정하지 않는다.
- 독자가 직접 의미를 해석하게 한다.
- 마지막 장면에서 처음 장면과 동일한 상황이 반복된다.

---

## 사용 가이드

LLM 호출 시 다음과 같이 전달한다:

```
장소: 모텔
시간: 새벽 3시 33분
주인공: 모텔 직원
이상 현상: 거울 속의 내가 실제 나보다 늦게 움직인다.
금기: 거울을 오래 바라보지 말 것
반전: 주인공은 이미 죽어 있었다.
결말: 마지막 한 문장으로 모든 상황을 뒤집는다.
```

이 풀을 그대로 주면 LLM이 항목을 조합해 이야기를 생성한다.
세부 톤·말투·세부 공포 메커니즘은 LLM이 자율적으로 결정.
