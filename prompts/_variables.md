# Random Variables (조합표)

각 변수에 **알파벳 코드**를 부여하고 무작위로 조합해 이야기를 생성한다.
직접 LLM에 넣을 때 코드로 짧게 표현하거나, 풀네임으로 풀어서 넣을 수 있다.

## Horror Level (L1-L5)

| 코드 | 강도 | 키워드 |
|---|---|---|
| L1 | 불안 | 이상한 소리, 사소한 시간 오류 |
| L2 | 의심 | CCTV 불일치, 존재하지 않는 사람 |
| L3 | 공포 | 누군가 따라옴, 공간 왜곡 |
| L4 | 극한 공포 | 정체 흔들림, 현실 조작 |
| L5 | 여운 | 마지막 한 문장 뒤집기 |

→ 자세한 정의는 `_horror_level.md` 참조

## 조합 수

`10 (Setting) × 7 (Protagonist) × 10 (Fear) × 10 (Trigger) × 7 (Ending) × 5 (Level)`
= **49,000 × 5 = 사실상 무한에 가까운 조합**

## 조합 코드 형식

`Setting-Protagonist-Fear-Trigger-Ending-Level`

예: `D-C-F-H-B-L3`
→ 지하철 + 택배기사 + 정체불명의 사람 + 문자 + 열린 결말 + Level 3

## 조합 예시

| 코드 | 의미 |
|---|---|
| `B-B-C-B-C-L4` | 군부대 + 군인 + 시간 반복 + CCTV + 순환 + 극한 공포 |
| `A-D-I-H-D-L3` | 폐교 + 대학생 + 존재하지 않는 사람 + 문자 + 정체 반전 + 공포 |
| `F-F-A-D-A-L2` | 병원 + 유튜버 + 귀신 + 사진 + 반전 + 의심 |
| `D-G-E-C-C-L3` | 지하철 + 직장인 + 공간 왜곡 + 거울 + 순환 + 공포 |
| `E-G-E-G-D-L4` | 아파트 + 직장인 + 공간 왜곡 + 엘리베이터 + 정체 반전 + 극한 공포 |
| `G-?-F-B-A-L5` | 산속 + 등산객(복수) + 정체불명의 사람 + CCTV + 반전 + 여운 |

## 조합 시 제약

LLM이 조합을 평가할 때 다음을 체크한다:

- [ ] **Protagonist × Setting** — 직업이 장소와 자연스러운가? (군인 + 군부대 ✓, 군인 + 바닷가 △)
- [ ] **Fear × Trigger** — 트리거가 공포 유형과 연결되는가? (거울 + 도플갱어 ✓, 꿈 + 시간 반복 △)
- [ ] **Level × Ending** — 강도와 결말의 분위기가 일치하는가? (L5 + 열린 결말 ✓, L1 + 정체 반전 ✗)
- [ ] **조합 고유성** — 최근 5회 안에 같은 Setting-Protagonist 조합이 안 나왔는가

## LLM 입력 형식 (간단)

```
Setting: D
Protagonist: C
Fear Type: F
Trigger: H
Ending: B
Level: L3
```

## LLM 입력 형식 (풀버전, 권장)

```
다음 조건으로 한국식 공포 단편을 작성하라.

[Setting]     D — 지하철 (막차 시간)
[Protagonist] C — 택배기사 (야간 배송)
[Fear Type]   F — 정체불명의 사람 (본 적 없는 얼굴이 따라붙음)
[Trigger]     H — 문자 (낯선 번호에서 메시지)
[Ending]      B — 열린 결말 (설명 없이 끝냄)
[Level]       L3 — 공포 (주인공을 누군가 따라옴)

톤: 1인칭, 무심한 직장인 화자.
분량: 1,500~3,000자, 단편 1편.
제외: "그날 이후 아무도 그를 보지 못했다" 같은 결말.
```
